# Fruity Weed landing-page prototype

A local Bootstrap page with the existing client logo, responsive header, animated mobile menu, and product carousel.

Open `dist/index.html` in a browser. Assets are local; no installation is needed.
Navigation and product links open the existing Fruity Weed shop. The carousel contains 12 product image cards and advances every six seconds. Some products share the shop's category artwork, as on the original site. Four cards appear on desktop, two on tablets, and one on phones. Arrows, dots, keyboard controls, and swipe are supported. Rotation pauses during hover or keyboard interaction, in hidden tabs, or when reduced motion is enabled.

Wishlist selections are stored locally in this prototype; they do not update the live WooCommerce wishlist. Product prices are copied for design review and are not a live feed. The rest of the page remains empty.

This is a static HTML/CSS/JavaScript prototype. PHP and WordPress integration will be a later step, once the design is agreed.

Bootstrap 5.3.3 is stored in `dist/assets/bootstrap.min.css`. The logo and category images were downloaded from the client's public website.

A private Sites project was reserved during initial setup. This local step has not been deployed.
